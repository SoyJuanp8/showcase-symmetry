# Database Schema

## Articles

The `articles` collection will store the articles created by the users (journalists).
This schema mimics the structure of the NewsAPI articles to ensure compatibility with the frontend.

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | String | Unique identifier of the article (Auto-generated by Firestore) |
| `author` | String | The author of the article (The user's name) |
| `title` | String | The headline or title of the article |
| `description` | String | A description or snippet from the article |
| `url` | String | The direct URL to the full article (if applicable, or internal link) |
| `urlToImage` | String | **Reference** to the image in Firebase Cloud Storage (path: `media/articles/{image_name}`) |
| `publishedAt` | String | The date and time that the article was published, in UTC (+000) (Format: `YYYY-MM-DDTHH:mm:SSZ`) |
| `content` | String | The unformatted content of the article |

### Firestore Path
`articles/{articleId}`

### Example Document
```json
{
  "author": "Juan Forero",
  "title": "Flutter is taking over the world",
  "description": "An in-depth look at how Flutter is becoming the dominant cross-platform framework.",
  "url": "", 
  "urlToImage": "gs://symmetry-showcase-2c2b8.appspot.com/media/articles/flutter_world.jpg", 
  "publishedAt": "2026-02-08T14:30:00Z",
  "content": "Flutter has seen massive adoption in recent years..."
}
```
